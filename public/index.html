Software Engineering & System Design Deliverable

About GameVerse & System Design Documentation

GameVerse: Digital Gaming and Exploration Platform is an academic web development project designed to help users explore games, discover multi-genre classifications, and compare illustrative game ratings and popularity scores. It demonstrates core software engineering principles including requirements analysis (SRS), modular client-side architecture, usability engineering, automated & manual testing, and Agile iterative development.

1. Problem Statement & Objectives

Problem Statement: Modern digital gaming storefronts often mingle discovery tools with commercial monetization, complex account gates, and opaque recommendation algorithms. Students and gamers looking for a clean, distraction-free taxonomy to explore games across eras (from 1997 classics like Tekken 3 to upcoming titles like GTA VI) lack a lightweight, offline-capable catalog and comparison portal.

Primary Academic Objectives:
  • Design a modular, zero-cost client-side web application using standard HTML5, CSS3, and Vanilla JavaScript.
  • Represent all 20 required games accurately with real release metadata, supported platforms, and clearly separated sample rating/popularity telemetry.
  • Implement multi-tag genre filtering so clicking broad categories like Action returns all 14 matching Action and hybrid Action titles.
  • Provide visual comparative analytics via Chart.js and persistent local favorites via browser localStorage.

2. Software Requirements Specification (SRS)

Functional Requirements (FR):
  • FR-01 (Catalog Display): Render all 20 specified games with bespoke cover art, title, genre, platforms, release year/status, sample rating, and sample popularity.
  • FR-02 (Multi-Genre Filtering): Filter games by primary or hybrid genre tags (e.g., selecting "Action" displays all 14 games containing Action).
  • FR-03 (Search & Multi-Criteria Sort): Filter by keyword, platform, release status, and minimum rating; sort by popularity, rating, release year, or title.
  • FR-04 (Conditional Trailer Action): Display the "Watch Trailer" button inside Game Details only when a valid trailer URL is present.
  • FR-05 (Visual Comparison): Compare 2+ selected games via dynamic Chart.js charts and a tabular specification matrix.
  • FR-06 (Local Favorites): Add/remove favorites persisted in window.localStorage without login or backend servers.
Non-Functional Requirements (NFR):
  • NFR-01 (Zero Commercial Cost): Must run locally on Windows/macOS/Linux laptops without domains, paid hosting, or payment gateways.
  • NFR-02 (Responsive Ergonomics): Fluid layout across Desktop (1280px+), Tablet (768px), and Mobile (375px) viewports.
  • NFR-03 (Data Integrity & Honesty): Clearly label demo statistics and distinguish released games from upcoming/TBA titles.
  • NFR-04 (Fault Tolerance): Procedural SVG cover generation + onerror fallback ensures zero broken images offline.

Agile Iterative Lifecycle

Developed across 4 structured sprints inspired by Agile Scrum methodology:

  1. Sprint 1: Requirements & Schema DesignCompiled accurate metadata for all 20 required games, separating historical facts from clearly labeled demo statistics.
  2. Sprint 2: Multi-Genre Filter & Search EngineImplemented substring + taxonomy tag matching so clicking "Action" retrieves all 14 Action & hybrid Action games.
  3. Sprint 3: Chart.js Analytics & LocalStorageBuilt interactive multi-game comparison charts and persistent local favorites.
  4. Sprint 4: UI Polish, Custom SVG Covers & QACrafted bespoke SVG cover posters for 100% offline reliability and verified all 8 test cases.

Scope & Limitations

  • 1. Illustrative Demo Statistics:Sample ratings and popularity scores are static educational datasets, not live API telemetry from Steam or PSN.
  • 2. Browser-Scoped Persistence:Favorites use localStorage, meaning saved favorites persist on the current laptop browser without cloud sync.
  • 3. Curated 20-Game Catalog:Designed specifically around the 20 academic benchmark titles spanning 1997 to upcoming releases.
  • 4. Non-Commercial Architecture:No payment gateways, digital rights management (DRM), or paid subscriptions are included.

Run Locally on Windows

No server installation, Node.js, or database setup is required to demonstrate GameVerse on your laptop:

# Option A: Direct Double-Click
1. Save index.html to a folder on your Windows Desktop.
2. Double-click index.html to open in Chrome, Edge, or Brave.
# Option B: VS Code Live Server
1. Open project folder in VS Code.
2. Right-click index.html → "Open with Live Server".
